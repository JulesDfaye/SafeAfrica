Reconnaissez les arnaques avant de perdre votre argent

SafeAfrica aide les citoyens africains à identifier les fraudes, protéger leurs données personnelles et signaler les situations suspectes.

Catégories principales

Arnaques Mobile Money

Faux agents, demandes de code OTP et faux gains.

Ne communiquez jamais votre code OTP, PIN ou mot de passe.

Phishing

Faux liens, SMS et e-mails imitant une banque ou un opérateur.

Ne cliquez pas sur le lien. Tapez vous-même l’adresse officielle.

Faux investissements

Cryptomonnaies, trading et rendements garantis trop élevés.

Aucun investissement sérieux ne garantit des profits rapides.

Usurpation d’identité

Comptes piratés, SIM swap et vol de données personnelles.

Activez la double authentification et contactez votre opérateur.

Catégories d’arnaques

Mobile Money

Signes : demande d’OTP, faux blocage, promesse de gain.

Contactez directement votre opérateur via son numéro officiel.

Phishing

Signes : lien urgent, fautes, demande de données bancaires.

Ouvrez vous-même le site officiel dans votre navigateur.

Faux investissement

Signes : rendement garanti, pression, paiement Mobile Money.

Méfiez-vous de toute promesse de profit rapide et garanti.

Usurpation d’identité

Signes : code reçu sans action, compte piraté, SIM bloquée.

Activez la double authentification immédiatement.
